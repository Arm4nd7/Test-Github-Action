Airbnb CI/CD

Airbnb es una plataforma que permite a los propietarios ofrecer servicios de alojamiento, proporcionando viajes seguros y conectando a personas con experiencias de hospitalidad a nivel mundial.

¿Cómo está actualmente?

Airbnb utiliza varios servicios de AWS:
Base de datos: Amazon RDS.
Amazon EC2 y Elastic Load Balancing: gestionan las aplicaciones, el almacenamiento en caché y distribuyen automáticamente el tráfico entrante, asegurando tiempos óptimos.
Amazon SQS: servicio de mensajería que sincroniza los repositorios.
Amazon EFS: sistema de archivos escalable que mantiene los espejos de GitHub sincronizados.

¿Por qué comenzó a usar CI/CD?

La inconsistencia en el manejo de datos, los problemas de tiempo de inactividad y las caídas frecuentes del sitio, junto con el creciente tráfico de la plataforma, hicieron evidente la necesidad de escalar su infraestructura.

¿Cómo se abordó el problema?

Airbnb migró su base de datos MySQL a AWS. Para manejar el tráfico de datos se utilizó Amazon EFS, lo que eliminó problemas de inconsistencia y facilitó la gestión del pipeline CI/CD.
Amazon SQS aseguró que no se perdieran cambios críticos durante los procesos de sincronización.

Etapas del proceso CI/CD

  • Etapa 1: Actualización de instancias individuales de los desarrolladores dentro del CRM desde el entorno de integración (SIT).
    Logros:
    • Facilita el desarrollo colaborativo.
    • Permite pruebas unitarias en entornos individuales.
    • Garantiza una integración fluida entre equipos.
  • Etapa 2: El código pasa por controles de calidad antes de llegar al entorno SIT, incluyendo análisis estático para cumplir estándares y buenas prácticas.
  • Etapa 3: Entorno de pruebas donde se realizan pruebas de aceptación del usuario y rendimiento. Se utiliza PTPaaS para pruebas de carga y rendimiento.

Conclusiones

La implementación de DevOps permitió una mejora significativa en una infraestructura a gran escala, optimizando la calidad del software, el flujo de trabajo de los desarrolladores y la experiencia del usuario final.
